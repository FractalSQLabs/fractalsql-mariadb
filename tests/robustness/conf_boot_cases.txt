# Each block is "case NAME EXPECT [conf=MODE] [key=CONTENT] [keymode=MODE]" followed by the
# configuration file body and a line "end". EXPECT is "start" (the daemon opens its socket)
# or "refuse" (it exits without listening). The placeholders below are replaced before use:
#   @SOCK@ socket path   @KEY@ HMAC key file   @UID@ the invoking user's uid
#   @DIR@  scratch dir   @LONG@ 20000 characters   @MANYKEYS@ 300 unknown keys
#   @UIDS80@ a list of 80 uids then @UID@   @LONGSOCK@ a socket path past the sun_path limit
# key=CONTENT replaces the key file's text (@RAND@ means 64 random hex digits).
